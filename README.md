# BASS PRO ReaPack Repository

This repository provides **BASS PRO** for Cockos REAPER via [ReaPack](https://reapack.com/).
Configured per [cfillion/reapack-repository-template](https://github.com/cfillion/reapack-repository-template).

## How to install in REAPER

1. Open **REAPER**.
2. Go to: **Extensions > ReaPack > Import repositories...**
3. Paste the URL:
   ```
   https://raw.githubusercontent.com/cfillion/reapack-repository-template/master/index.xml
   ```
4. Click **OK**.
5. Go to: **Extensions > ReaPack > Browse packages...**
6. Search for **BASS PRO**, right-click and click **Install**.
7. Click **Apply** in the bottom-right corner of the window.

## Included Packages

- `Plugins/BASS PRO.jsfx`: Sound-shaping suite and 7-band dynamic leveler for bass guitar.
